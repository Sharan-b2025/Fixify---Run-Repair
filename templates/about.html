About Fixify

Fixify Run & Repair is an AI-powered coding companion built to make debugging, understanding, and improving code feel less intimidating — for absolute beginners and experienced developers alike.

🎯 Our Mission

Learning to code is hard enough without cryptic compiler errors getting in the way. Fixify exists to translate confusing error messages into plain language, walk learners through code line by line, and give honest, constructive feedback — the way a patient mentor would, available any time, for free.

🛠️ What We Built

Three tools in one workspace: an Analyzer that finds every bug in your code and explains how to fix it, a Code Explainer that walks through your program one line at a time in simple 8-word explanations with voice narration, and a Code Reviewer that scores your code out of 100 and tells you what's great, what's fine, and what to improve.

⚙️ How It Works

Fixify runs on Google's Gemini models through a lightweight Flask backend. Your code is sent securely to Gemini for analysis and never stored beyond what's needed to generate a response. No account, no signup, no cost to use.

🚀 Who It's For

Students learning their first language, self-taught developers debugging a tricky script, and anyone who wants a second pair of eyes on their code before shipping it.
